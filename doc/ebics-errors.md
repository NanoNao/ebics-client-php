# EBICS Return Codes

EBICS return codes are 6-digit codes returned by the bank server in EBICS responses. They indicate success, warnings, or errors during technical processing or business-related validation of orders.

## HAC (EBICS Customer Acknowledgement) Reason Codes

HAC (administrative order type `HAC`) provides status information about all actions and results that occur while uploading, downloading, or signing files. The reason codes below are used in the `<Rsn><Cd>` element of the HAC response.

| Code   | ISO Name                                    | Definition                                                                                                                                                     | Applicable Action Types                                                            |
|--------|---------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------|
| `AM05` | Duplication                                 | The data digest of the transmitted order data is already known on the bank server (order data with the same data digest was transmitted recently)              | `FILE_UPLOAD`                                                                      |
| `AM21` | LimitExceeded                               | Transaction amount exceeds limits agreed between bank and client                                                                                               | `ES_VERIFICATION`, `VEU_VERIFICATION`                                              |
| `DS01` | ElectronicSignaturesCorrect                 | The Electronic Signature(s) are correct                                                                                                                        | `ES_VERIFICATION`, `VEU_VERIFICATION`                                              |
| `DS02` | OrderCancelled                              | An authorized user has cancelled the order                                                                                                                     | `VEU_CANCEL_ORDER`                                                                 |
| `DS03` | OrderNotCancelled                           | The user's attempt to cancel the order was not successful                                                                                                      | `VEU_CANCEL_ORDER`                                                                 |
| `DS04` | OrderRejected                               | The order was rejected by the bank side (for reasons concerning content)                                                                                       |                                                                                    |
| `DS05` | OrderForwardedForPostprocessing             | The order was correct and could be forwarded for postprocessing                                                                                                | `VEU_VERIFICATION`                                                                 |
| `DS06` | TransferOrder                               | The order was transferred to EDS                                                                                                                               | `VEU_FORWARDING`                                                                   |
| `DS07` | ProcessingOK                                | All actions concerning the order could be done by the EBICS bank server                                                                                        |                                                                                    |
| `DS08` | DecompressionError                          | The decompression of the file was not successful                                                                                                               | `FILE_UPLOAD`, `FILE_DOWNLOAD`, `ES_UPLOAD`, `ES_VERIFICATION`                     |
